# session guide for Claude

Every Claude Code session loads this file. It is pointers only; the substance
lives in the canon documents below.

## Read before working

- `PHILOSOPHY.md` — THE LAWS: which modules of `../claude_mds/laws/` this
  project follows, and its own laws. When a change and a law conflict, the
  law wins or the law is amended in the same change set.
- `PROVENANCE.md` — who wrote each file and what has actually RUN. Code that
  no scenario exercises is a draft, whoever wrote it.
- `RULINGS.md` — OPEN rulings on the simulation architecture, newest
  first. Check it before touching the kernel; prepend new assumptions.
- `CHANGES.md` — the sync log, newest first. Prepend an entry per change set.
- `FINDINGS.md` — what the work found: measurements, defects, surprises.
  Newest first. A RULINGS entry is ONE decision in a few lines, never a
  diary: what was found goes here, what was changed goes to CHANGES.md.
